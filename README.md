# 2026-KB-AI-Challenge
금융과 AI 의 만남

## 공모전 개요
<details>
  <summary><b>주제</b></summary>
  
   ### 소상공인 금융 지원 에이전트

     - 지역 상권, 경기지표, 소비 트렌드, 정책자금 정보를 종합적으로 분석하여 소상공인의 경영 의사결정을 지원
     - 창업 및 운영 단계에 필요한 금융 상품을 추천하고, 정부 지원 사업과 정책자금을 안내하며, 경영 환경 변화에 따른 맞춤형 금융 제안

  ---
</details>


## 기획
<details>
  <summary><b>문제 정의</b></summary>

  # 문제 정의

  현재 소상공인은
  - 금융상품이 너무 많다.
  - 정부지원사업이 너무 많다.
  - 지원조건이 복잡하다.
  - 금융용어가 어렵다.
  - 어디서부터 준비해야 하는지 모른다.
  - 어떤 정책이 자신에게 맞는지 찾기 어렵다.
  
  결국
  
  > **정보는 많지만 나에게 맞는 정보를 찾기 어렵다.**
  
  AI가 대신 분석해서
  
  > "사용자에게 가장 적합한 금융상품 + 정책"
  
  을 추천한다.
